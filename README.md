# Studio Lead

The tool that runs a reformer pilates studio every day. Built in the evenings beside a full-time job, about 2,000 commits, in daily use. It saves the studio roughly half a position. The code is private, it runs a real business. This page shows what it does and what it taught me. Product site: [studiolead.ai](https://www.studiolead.ai).

## What it does

Studio Lead reads the booking system and turns the data into the week's actions for the studio owner.

- **Lead detection.** New trial bookings and inquiries become a list of people to follow up with, so no lead waits in an inbox.
- **Drop-off detection.** Members whose visit pattern breaks are flagged before they cancel.
- **Churn and cancellation alerts.** An agent informs the owner and the coach on duty, with the suggested next step. A person decides before anything reaches a member.
- **Behavioral nudging.** Personal outreach at the moments that matter, after a first class, after a missed week, before a membership renews.
- **Analytics.** Utilization by class and coach, revenue by channel, the client journey from trial to active to community, and the financial view the owner needs for planning.

## How it is built

A workflow layer on top of the existing booking platform, no system switch for the studio. Deterministic rules where the answer is known, a model where judgment is needed, and the owner in the loop for every outbound message. It is maintained by the person who uses it, which is the reason it is still alive.

## Why it did not become a startup

I tried. The market pays too little per studio to carry a team that keeps a tool like this alive in other people's houses. The tool stayed, the startup did not. What I took from it is the question I work on now: how does a tool that lives in one house come to live in another, without its builder in the room.
